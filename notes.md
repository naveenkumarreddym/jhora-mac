Unofficial macOS package of **Jagannatha Hora 8.0** by P.V.R. Narasimha Rao, bundled with Wine Staging 11.17.

**Install:** open the `.dmg`, drag *Jagannatha Hora* to Applications, then on first launch allow it in **System Settings → Privacy & Security → Open Anyway**. First launch takes about a minute.

Requires macOS 11 or later; Apple Silicon Macs need Rosetta 2. See the [README](https://github.com/naveenkumarreddym/jhora-mac#readme) for details and limitations.
